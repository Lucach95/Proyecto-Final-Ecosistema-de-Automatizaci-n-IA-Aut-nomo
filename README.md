Proyecto Final: Ecosistema de Automatización IA Autónomo: Este ecosistema es un asistente interno de IA para empleados de atención al cliente de una tienda tecnológica. Sus funcionalidades principales son consultar stock en tiempo real, verificar políticas comerciales y gestionar cancelaciones de ventas de manera autónoma, integrándose con bases de datos y requiriendo validación humana para acciones críticas.
